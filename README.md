# Orbit Messenger

A front-end demo of a messaging web app: chats, groups, updates, communities, calls and settings, with light and dark themes.

Everything is in `index.html`. Open it in a browser, or deploy the folder as a static site (no build step).

## Demo limits

- People are fictional and replies are automatic.
- Calls and voice messages are simulated.
- Data is stored in the browser. There is no login, server or encryption.
